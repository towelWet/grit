# Delivery Sequence

## Current: recovery-safe storage foundation

Exact-byte BLAKE3 objects, atomic writes, snapshots, compare, restore, verify,
doctor, journal, and safety backups exist. Git-shaped command and internal names
are transitional. Lanes, Grains, Reviews, networking, and forge objects do not.

## Next: truthful daily surface

Add Project, Draft, Save, Timeline, Compare, Undo, Restore, and Shelf commands.
Journal Draft mutations before success and make checkpoints inspectable. Retain
compatibility aliases only with explicit transitional labeling.

## Then: safe parallel work

Add Lane overlays, isolated Projections, Task Contracts, ownership, preimage
checks, parser-owned Grain identities, structured Overlaps, and agent labeling.

## Then: durable collaboration

Add signed identities, Review Requests, Issues, Comments, Releases, Receipts,
transactional Combine, preservation proof, serialized Main, and CAS updates.

## Then: distributed development record

Add P2P Send/Receive/Sync, quarantine ingestion, resumable bounded transfer,
Forge Protocol conformance tests, federation, and disposable index rebuilds.

## Last: compatibility edges

Add explicit Git import/export and hosted-PR bridge. Git refs never become native
authority. Bridges remain removable adapters outside the deterministic core.
